# **App Name**: SmartCart

## Core Features:

- Item Management: I will upload a CSV file that will contain a list of grocery items and their details. Display them properly.

## Style Guidelines:

- Primary color: Fresh green (#A2D9A2) to evoke feelings of freshness and health.
- Background color: Soft white (#F5F5F5) to create a clean, uncluttered interface.
- Accent color: Muted yellow-green (#B0CF92) for interactive elements and highlights.
- Headline font: 'Poppins', sans-serif, for headlines, paired with 'PT Sans' for body text.
- Use clear, minimalist icons representing grocery items for easy recognition.
- A clean, intuitive layout that prioritizes easy navigation and readability.
- Subtle animations and transitions to provide feedback on user interactions.
